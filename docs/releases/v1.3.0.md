## 写作更顺手，分发结果更清楚

这版主要改善 Markdown 写作、图片导入、模板体验，以及保存和分发的可靠性。

### 旷野 · 野生观察

新增纸色底、墨黑大标题、锈红重点句的排版主题与写作模板。用具体场景、追问和有依据的判断引导阅读，偏向有锋芒的独立刊物。

在「撰写 → 模板」选择「旷野 · 野生观察」。模板可切换正文骨架与排版效果；内置长文、测评、研究笔记、图文教程，也可把自己的正文与图片保存为模板。

### 写作与图片

- 新增 Markdown 源码切换、专注模式、隐藏预览及小窗口布局；`Ctrl+Alt+M` 切换编辑模式。
- 停笔后自动保存，无标题新稿也能保存；切稿和退出前保存，保存过程中继续输入不会被旧版本覆盖。
- 增加异常退出恢复副本、删除撤销，同名文章与移动归档不覆盖已有稿件。
- 图片选择、粘贴与拖入统一处理：修正方向、处理尺寸、去重，保留原图、透明通道与 GIF 动画。移动文章时携带配图。
- 减少实时预览闪烁；缓存公式和表格渲染；文章预览隔离于沙盒。

### 分发与数据

- 区分成功、部分成功、失败和需要人工确认；重试只处理失败平台，排队任务可取消。
- 任务日志不再阻塞执行线程；修复重启后的历史查询与手机选稿配图路径。
- 数据目录迁移安排到下次启动，复制并更新图片路径后切换，保留原目录。
- 增强 API 参数校验和路径处理；新配置默认仅允许本机访问，手机访问可在设置中开启。

### 下载与升级

- **安装版**：`PushAnything_Setup_1.3.0.exe`，Windows 10/11 x64，安装到当前用户目录。
- **绿色版**：`PushAnything.exe`，放到单独目录运行。升级现有绿色版时，退出旧程序后替换 EXE，保留原有配置和数据。
- **模板包**：`PushAnything-Wild-Template-1.3.0.zip`，包含 Markdown 骨架、完整示例和 HTML 预览。

发布文件不包含个人配置、账号凭证、登录资料或草稿。运行需要 Microsoft Edge / WebView2。

### 验证范围

22 项本地回归测试、15 项 Edge 界面检查、4 项真实 WebView2 桥接检查通过；打包 EXE 的资源与隔离 API 启动已验证。CI 构建前也会执行回归测试。

测试使用临时数据，未向真实账号投稿。第三方平台的实际上传和最终排版仍需使用时确认；知乎和头条的页面变化可能影响浏览器自动化。单文件 EXE 首次启动需要解包，耗时受磁盘和系统环境影响。
